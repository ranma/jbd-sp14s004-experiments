Verified GPIO:
PA0: ALT; UART_RX
PA1: OUT; AZ3714 WAKEUP
PA7: ALT; SWS (debug)
PB1: ALT; UART_TX
PB5: OUT: Blue LED!
PB6: OUT; default high; triggers low-power state after a second or so if low
PC0: I2C_SDA to AZ3714
PC1: I2C_SCL to AZ3714
PC3: IN; ext pull-up; Power switch (B+ via 10k to FET/transistor; 0 if closed, 1 if open)
PC4: IN/PULLUP: Charger detection? Goes to fet/transistor that is connected via 3MOhm to pads between CFET/DFET
PD2: STX pin data output (pulls down to low; open-drain)
PD3: OUT, external pull-down: External watchdog, CPU reset if not toggled for some time
PD4: AZ3714 ALERTN

Mostly verified:
PB4: ALT; PWM4(_N) not connected (used only as 10kHz timer)
PD2/PD7: STX/Onewire: PD2 output, PD7 input?

STX:
  Open-drain output for ~10kHz one-wire comms, needs external pull-up resistor.
  Original firmware writes some data in manufacturing mode.
  Self-clocking data encoding: 001 or 011 for each 0/1 (3.3kbaud data rate?)
  (i.e. somewhat similar to SWS encoding)

Unverified GPIO:
PB7: IN; Probably unconnected
PC2: OUT; Probably unconnected
PD1: ??? not routed to 32-pin package pins
